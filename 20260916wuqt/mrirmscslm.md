# 解决“最后一公里”痛点  12月1日起港大医院大巴接驳地铁

> 更新时间：2026-09-16 (UTC+8)

到香港大学深圳医院看病的市民不断增多，他们对公共交通的需求也越来越大。由于开业仅三年多，公共交通配套尚在不断完善。目前已有6路公交车直达医院门口，但周边一些路线密集的大型公交站台（红树林站、康佳集团东站、金海燕花园站等）以及最近的地铁站罗宝线（1号线）侨城东站离医院还需要步行10-15分钟，“最后一公里”的问题，已经成为很多市民到港大深圳医院就医的“痛点”。

为方便市民就医，港大深圳医院从 9月28日起举办三周年“健康节”，先后推出简易体检和专科诊金50%优惠。从12月1日起，医院再推交通便民服务，试行免费大巴接驳计划，派出医院大巴到就医人流最大的地铁侨城东站C1出口往返接送市民，约20分钟一班，在周一到周五上午9:00-12:00和下午15:00-17:00运行。试行一个月后，医院会进行检讨，对服务方案成效评估优化，以进一步方便市民。

**直达医院的地铁2016年底开通**

港大深圳医院是深圳市公立医院的改革试点，开业三年多来，以全面预约制、先全科后专科、团队式诊疗等国际化的改革模式闻名，吸引越来越多的市民就诊。虽然医院规划的2130个停车位非常充裕，但医院周边公共交通配套仍有待完善。

三年多来，港大深圳医院与政府交通规划部门一直在积极拓展医院的公共交通服务，先后增设2个直达医院门口的公共汽车站点“**港大医院站**” （45 路、49 路、B603路、B706路、M391 路）和“**港大医院总站**” （B706路、M391 路）。

地铁方面，在建的深圳地铁9号线将与港大深圳医院无缝连接，预计2016年底正式开通，市民可坐地铁直达医院。根据深圳地铁集团的消息，目前9号线全线已经实现双线“轨通”，正在进行车站装修、设备安装调试。9号线开通后，医院南侧的滨海大道地铁施工封闭路段也将恢复通车，方便市民。
