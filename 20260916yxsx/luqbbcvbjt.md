# 怀孕三个月吃什么好

> 更新时间：2026-09-16 (UTC+8)

怀孕三个月吃什么好

怀孕第三个月虽然是关键期，但由于胎儿体积尚小，所需的营养不是注重量的多少，而是注重质的好环，尤其需要蛋白质、糖和维生素较多的食物，受孕11周以后，由于胎儿迅速成长和发育，需要营养也日渐增多。蛋白质：怀孕第三个月要尽量保证准妈妈的蛋白摄入量，可以多方面摄入，植物蛋白和动物蛋白都可以。准妈妈这时可根据自己的口味、习惯，想吃厚味的食物，就选择猪肉、牛肉、鸡肉等做成红烧肉，罐焖牛肉、辣子鸡等来吃；想吃清淡的就选择鱼、虾或各种肉馅做成清蒸鱼、清炒虾仁、蒸肉饼来吃。如果什么肉都吃不下去，还可以选择豆制品及口蘑、鸡腿磨等菌类来补充蛋白质。
 
怀孕三个月的症状

怀孕三个月九大症状：

1、停经：这是一般人最常注意到的怀孕征兆，只要是一般正常生育年龄的女性，平时月经正常，在性行为后超过正常经期两周，就有可能是怀孕了。但并非所有月经没来就是怀孕了，停经的原因有很多，可能是因为卵巢机能不佳，或荷尔蒙分泌不正常，工作忙碌，考试紧张等等，都会引起月经迟来的现象，所以最好还是要经过医师的诊断，才是最安全的。

2、常有恶心、呕吐的感觉：几乎很多怀孕初期的女性都时常会有恶心、呕吐的感觉，特别是在早晨的时候。这些症状都是因人而异的，有些人的症状相当轻微，有的则是很严重。除非是恶心、呕吐的非常厉害，才需要就医，否则这些都是怀孕初期的正常现象。很大一部分地区孕妇进入孕中期就不会在出现恶心、呕吐的现象了。

3、乳房变大、变敏感：乳房敏感、胀痛也是怀孕早期的征兆之一，这是由于体内激素水平提高所引起的。这种胀痛感与你经期前的感觉很相似，只是更强烈一些。这种怀孕征兆会在你怀孕3个月之后有明显好转，因为那时你的身体就已经适应孕期荷尔蒙的改变了。

4、腹胀：怀孕早期荷尔蒙的变化可能会让你感到胀气。一些女性在经期到来之前，也会有这种感觉。这也就是为什么怀孕早期在你的子宫还很小的时候，你就会觉得衣服的腰部紧绷绷的原因。

5、基础体温升高：基础体温可以反映安静状态下身体能量代谢情况。育龄女性的基础体温与卵巢激素周期变化有关，排卵后体温会升高0.3-0.5℃，直至月经前1-2天或月经第一天，如果基础体温上升后月经到期未来，而基础体温持续不降达16天之久，则受孕的可能性较大。如持续3月，那么基本可以肯定是怀孕了，但还需要排除其可使体温升高因素如全身感染疾病、感冒等等。

6、尿频：怀孕后不久，你会发现自己总往厕所跑。这是为什么呢?主要是因为在怀孕期间，体内的血液以及其他液体量增加，导致更多的液体经过肾处理排入膀胱，成为尿液。尿频可能会早在你刚刚怀孕6周时开始出现。随着孕期的推进，不断长大的宝宝会给你的膀胱施加更大的压力，怀孕早期的尿频症状可能会继续下去，甚至更加严重。

7、对气味更加敏感：怀孕后女性会对气味变得非常敏感。怀孕初期可能会受不了炒菜的油烟味或茶叶的气味，某些香味还会让你作呕。跟疲倦一样，尽管还没有人能够确定这是为什么，也可能是由于你体内急速增加的雌激素所导致的。另外，你可能还会发现，那些平时你很喜欢吃的东西，突然间也会让你觉得恶心。

8、疲倦：有的女性怀孕后会突然感到疲倦，甚至觉得筋疲力竭。目前还没有人确切地知道怀孕早期的疲劳症状是由什么引起的，不过，快速增加的孕酮(也叫“黄体酮”)水平可能会使你感到特别困倦。进入怀孕中期，你会开始感到精力比孕早期更充沛了，但到了怀孕晚期，疲倦感通常会再次出现。因为，这时你的体重会大幅增加，而且孕期常见的不适反应也会影响你晚间的睡眠质量。

9、早孕自测呈阳性：早孕检测结果阳性应该是最确凿的怀孕征兆了。许多早孕自测试剂在女性错过月经1周后，才能测出大部分的怀孕。所以，如果你是在这之前做的测试，并且得到的是阴性结果，过几天，你可以再测一次。一旦你自测出阳性结果，一定要到医院做进一步的检查。
 
怀孕三个月能同房吗

如果你因为早产接受过治疗，或者孕期出现其他问题，比如子宫颈缩短或扩张、羊水流出、前置胎盘、阴道出血，有流产史，一定要先问问医生，你是否仍然能够过性生活。

在一些情况下，你是需要避免性生活的。但一般来说，过性生活也是可以的，一些怀孕书籍和医生可能告诫你在孕期前3个月和最后3个月过性生活是不安全的，但是最新的医学证据显示，只要你在孕期身体一切正常，那么在生理上没有理有让你和爱人在怀孕期间停止过正常的性生活。在英国、美国和很多其他国家，医生们也都认为在正常情况下孕期性生活是安全的。但是，如果你在怀孕初期出现任何突破性或少量出血症状，医生可能会建议你在孕期头14周内不能有性生活。
 
怀孕三个月饮食禁忌

一般来说，怀孕初期，也就是前三个月，是宝宝发育神经的时候，所以在这个时候，就要尽量的避免去接触电脑，电磁炉等高副射的电器，电器辐射大家都知道，而长期的接触电脑也会有导致胎儿畸形或者是流产的可能。还有就是，准妈妈们注意一定要纠正偏食的不良习惯，常食和多食富含叶酸的食物，如菠菜、牛奶、动物肝脏、土豆、水果、西红柿等。
 
怀孕三个月的注意事项

怀孕三个月事实上还是处于早孕的那个阶段的，所以由于早孕反应，以及增大的子官压迫胃和其他消化器官，孕妇常会出现消化不良，食欲不振等情况。这时准妈妈们平时要注意除了少吃多餐之外，在饮食结构方面也应该要挑选一些容易消化的、新鲜的食物，尽量避免吃油炸、辛辣的食物。
