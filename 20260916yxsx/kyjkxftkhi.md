# 钦州妇幼做三代试管怎么样？

> 更新时间：2026-09-16 (UTC+8)

我和我妻子结婚有好几年了，但是一直都没有孩子。刚结婚的时候怀孕过一次，但是生下来不久就夭折了，之后就再也没有怀上了。最近家里催得紧，于是就去医院做了检查，准备要个孩子。但是医生检查出我染色体异常，建议做三代试管，避免生下带有遗传性疾病的孩子。我想去钦州市妇幼保健院做，想知道钦州妇幼做三代试管怎么样？

钦州妇幼目前还不能做三代试管，只能开展第一二代试管婴儿技术。有想做三代试管婴儿的患者可以去桂林市的解放军第九二四医院，或是柳州市的柳州市妇幼保健院。这两家医院是广西省内目前被卫计委批准开展第三代试管婴儿技术的医院。钦州妇幼目前能开展的辅助生殖技术只有夫精人工授精技术、常规体外受精-胚胎移植技术、卵胞浆内单精子显微注射技术。
医院信息医院名称钦州市妇幼保健院医院等级三级甲等医院类别妇幼保健院成立时间1974年诊疗科目内科/外科/妇产科/儿科医院地址钦州市安州大道1号
钦州市妇幼保健院是钦州市唯一一所集医疗、妇幼保健、科研、教学、健康教育指导为一体的国家三级甲等妇幼保健院。该院生殖助孕中心可以开展辅助生殖技术，大致情况如下：

- 1. 生殖助孕中心拥有价值近1000万元的专为开展人工授精和试管婴儿技术配备的高新仪器设备；
- 2. 科室人员共有17人，其中正高1人，副高2人，中级职称6人，研究生8人，所有医务人员均到卫生部指定的培训机构接受严格正规的技术培训，熟练掌握人类辅助生殖医学知识和操作技能；
- 3. 2010年6月，通过自治区卫生厅开展夫精人工授精技术的评审；
- 4. 2012年8月，通过自治区卫生厅开展体外受精-胚胎移植（“试管婴儿”技术）及卵胞浆内单精子显微注射技术评审，成为北部湾沿海地区唯一一家能开展试管婴儿的医院。
该院于2010年6月成为北部湾沿海地区可以开展人类辅助生殖技术的医院，同时医院设立优生遗传科，在钦州市开展外周血及羊水染色体核型分析、地贫基因检测、唐氏快速诊断(FISH)等高端技术及各种遗传疾病的诊断和治疗。
